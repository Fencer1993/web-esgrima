# Guía del panel de la web

Panel: **https://www.esgrimatorremolinos.com/admin/**

## Entrar
1. Abre el panel y pulsa **Sign In with GitHub** (o **Sign In Using Access Token** si aún no está activado el botón).
2. Necesitas una cuenta de GitHub con permiso de edición en el repositorio del club. Pídeselo a la dirección técnica.

Los menús del programa están en inglés; todas las secciones y campos del club, en español.

## Qué se puede cambiar
| Sección | Para qué |
|---|---|
| Horarios | Grupos, días, horas y notas en letra pequeña |
| Precios | Cuotas, bonos y licencias federativas |
| Equipo y deportistas | Entrenadores y deportistas, con foto y palmarés |
| Galería de fotos | Subir, quitar u ordenar fotos (las primeras salen en la cinta de la portada) |
| Preguntas frecuentes | Añadir o editar preguntas |
| Clases y valores | Frases de cada clase y de los valores |
| Textos de las páginas | Títulos y entradillas de cada página y textos de la portada |
| Datos del club | Teléfono, correo, dirección, Instagram y datos legales |

## Publicar un cambio
1. Edita y pulsa **Save**.
2. El cambio se publica solo en la web en 2-3 minutos. Recarga la página con Ctrl+Shift+R para verlo.

## Fotos
- Sube la foto tal cual, también desde el móvil: se convierte a WebP y se reduce sola.
- En **Pie de foto** escribe qué pasa ("Podio en Jaén…"); en **Qué se ve en la foto**, una descripción corta para Google.
- Lugar: **En nuestra sala** (tarima, armeros, espejos) o **Competiciones** (cualquier otro pabellón).
- Sube solo fotos con permiso de las personas que salen, sobre todo de menores.

## Si algo sale mal
Cada cambio queda guardado en el historial de GitHub y se puede deshacer. Si la web no se actualiza o algo se ve raro, avisa y se revierte.
